# Twin Rivers Concrete Website

Custom marketing website built for Twin Rivers Concrete, a client of Chance IT Studio.

## What it does

A business website for a concrete contractor in Brighton, IL. It includes a photo gallery of past jobs (patios, retaining walls, water features, firepits), a Google Maps service area embed, a contact form with math captcha and honeypot spam protection, and owner bio sections. Adding a new job photo is a drop the image in, update one HTML block, commit, and push, since every push to main auto-deploys.

## Tech stack

- Vanilla HTML, CSS, JavaScript (no framework, no build step)
- Google Maps embed
- Cloudflare Pages (hosting, auto-deploys on push to main)
